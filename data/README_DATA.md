# Data Dictionary  
This folder contains the raw and cleaned datasets used in the Ecommerce Sales & Profit Analysis Dashboard.  
All data was cleaned and standardized using Python (Pandas) in the `python_dataCleaning/` directory.

## 🧼 Raw vs Cleaned Data

### **raw/**  
Contains the original CSV files exactly as provided. These files may include:
- Missing values  
- Inconsistent date formats  
- Mixed data types  
- Duplicate rows  
- Unmapped categorical IDs  

### **cleaned/**  
Contains the processed CSVs generated by the Python cleaning notebook:
- Standardized date formats  
- Normalized column names  
- Removed duplicates  
- Corrected data types  
- Added calculated fields (profit, negative profit flag)  
- Mapped categorical IDs to readable labels

# 🧠 Notes on Cleaning Process

The Python notebook (`python_dataCleaning/ecommerce_datacleaning.ipynb`) performs:

- Date parsing and normalization  
- Column renaming for consistency  
- Removal of duplicate rows  
- Conversion of numeric fields to correct types  
- Creation of `profit` and `is_negative_profit` fields  
- Mapping of category/sub‑category values  
- Export of cleaned CSVs into `/data/cleaned/`

---

# 🔁 Reproducibility

To regenerate the cleaned datasets:

1. Open the Jupyter notebook in `python_dataCleaning/`  
2. Run all cells  
3. Cleaned CSVs will be saved automatically to `/data/cleaned/`
